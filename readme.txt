Music Studio — an ElevenLabs album builder (baseline: Tachyread's audiobook builder).

Build/edit/manage AI music: curate prompts, generate songs via the ElevenLabs Music API,
splice in dialog (TTS) and your own uploads, reorder + set per-track volume, preview, and
export as an album. Everything you create is auto-mirrored to a local backup folder, and an
API spend dashboard estimates your ElevenLabs cost.

Run:
  cd app
  npm install
  npm run dev        # http://localhost:5173

Then open Settings and paste your ElevenLabs API key.

See app/README.md for details.
